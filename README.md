# Rock Paper Scissors
A Python command-line Rock Paper Scissors game where the player competes against the computer in multiple rounds, with each choice represented using ASCII art.

## Features
- Random computer choices
- Rock, Paper, Scissors gameplay
- Win, loss, and tie tracking
- Score tracking
- Input validation
- ASCII-art representation of choices
- Option to play multiple rounds
- Displaying overall outcomes at end

## How to Run
Run the following command:
```bash
python rock_paper_scissors.py
```

## Concepts Practiced
- Python functions
- Dictionaries
- Loops
- Conditional statements
- Input validation
- `random` module
- `match-case`
